## 候補を選んで挿入する

コマンドを入力すると、入力位置の近くに候補と説明が表示されます。キー入力のフォーカスはターミナルにあります。

候補は1行ずつ並び、候補名とアイコンを種類ごとに色分けします。選択中の行は背景色と左端のマーカーで示し、その候補の説明を下部のフッターに表示します。説明がない場合は種類名を表示し、ディレクトリには`folder`と表示します。長い候補名や説明は省略表示します。

ポップアップは固定のダーク配色です。候補の種類は色に加えてアイコンの形でも区別できます。

| キー | 操作 |
| --- | --- |
| ↑ / ↓ | 表示中の候補を選択 |
| Tab / Enter | 選択した候補を挿入 |
| Esc | 候補を閉じる |
| 行末の→ | 表示中の履歴予測を確定 |

Enterで候補を挿入した後、次のEnterでコマンドを実行します。挿入やEscで閉じた直後は、入力内容を編集するまで候補を再表示しません。

figfigの候補一覧が有効な間は、候補の表示がないときにTabを押しても入力はそのままです。候補一覧を無効にしたとき、一時停止中、ヘルパーとの接続が切れたときは、Tabは元のzsh操作に戻ります。

## 補完できる内容

| 種類 | 色 | 入力例 | 候補の元データ |
| --- | --- | --- | --- |
| コマンド名 | シアン | `gi` | 組み込み定義、PATH上の実行ファイル、シェルコマンド |
| サブコマンド | ミント | `git ch` | git、brew、npm、pnpm、dockerの組み込み定義 |
| オプション | 黄 | `git status --s` | コマンド・サブコマンドの定義 |
| ディレクトリ | 青 | `cd src/` | 作業ディレクトリと入力中のパス |
| ファイル | 紫 | `cat READ` | 作業ディレクトリと入力中のパス |
| Gitブランチ | ピンク | `git switch ` | 現在のリポジトリのローカルブランチ |
| package scripts | オレンジ | `pnpm run ` | 作業ディレクトリの`package.json`にある`scripts` |

パッケージ名、Dockerコンテナ名、任意のFig仕様やzsh補完関数の読み込みは、現在の組み込み候補の範囲に含まれていません。詳細は[対応環境](../reference/compatibility.md)に記載しています。

## 履歴予測を使う

入力した文字列で始まるコマンドを、現在のzshの履歴から探します。行末に続きが表示されたら、→で確定できます。

履歴予測の有効・無効を切り替えるには次を実行します。

```bash
figfig config set history false
figfig config set history true
```

履歴の検索と表示はzsh内で行います。履歴ファイルはzsh側の設定で管理します。

## 一時停止と再開

```bash
figfig pause
figfig resume
```

一時停止は、現在のヘルパーが終了するまで有効です。常用する設定は[設定ガイド](configuration.md)を参照してください。

## 候補をJSONで調べる

```bash
figfig complete 'git ch'
figfig complete 'pnpm run ' .
```

`complete`はローカルの補完エンジンの応答を出力します。`visible`はこのコマンドでは`false`になり、`candidates`で生成された候補を確認できます。
