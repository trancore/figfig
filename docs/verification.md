### Zedで表示されない場合の再調査

Zed 1.28.1で、シェル連携・描画ヘルパー・アクセシビリティ・候補設定は正常だが、パレット入力メソッドは登録済み・無効・未選択と確認。`TISEnableInputSource`は0を返しても無効のままで、ユーザーの明示的な許可を得て実行した `TISSelectInputSource` は-50を返した。初回登録後のmacOSへのログインし直しは未実施だった。

再ログイン後もパレットは無効だったため、Zedでカーソル位置を取得できない場合は、アクセシビリティで前面ウィンドウの位置を取得し、同じグラフィカルなポップアップを下部に配置する。ヘルパーは起動時にZedのフォーカスを維持する。Zed 1.28.1を前面にした状態で本番ヘルパーと検証用zshを接続し、`git f` でWindowServerに320×42ポイントの補完ウィンドウが表示されることを確認した。Tabで `git fetch ` が挿入され、候補ウィンドウは閉じた。

下部ターミナルの配置修正では、実環境と同じ1,458×342ポイントの表示領域を持つ検証用zshを使用した。Zedを前面にした状態で3行目と9行目のカーソル応答を模擬し、それぞれ入力行の下に補完ウィンドウが移動することを確認した。Tabで候補が挿入され、ウィンドウは閉じた。

## 自動検証の担当範囲

| レベル | 対象 | 実依存／モック | コマンド |
| --- | --- | --- | --- |
| Unit | 入力解析、引用、状態更新、遅延応答、通信フレーム、CLIのNUL区切り入力 | ファイルなし、インメモリのストリーム | `cargo test -p figfig-core --lib`、`cargo test -p figfig-cli` |
| Component | 選択行とフッター説明の関連付け、空の候補一覧、説明なしのディレクトリ | React・jsdom | `pnpm test` |
| Integration | パス、Gitブランチ、package scripts | 一時ディレクトリと実Git | `cargo test -p figfig-core --test completions` |
| Integration | ZLE・Rustブリッジ・ソケット、Enter、Tab、上下、履歴、接続断 | 実zsh・PTY・Rust CLI、テスト用バックエンド | `pnpm run test:shell` |
| Integration | CLIの初期設定・検証・設定通知・一時停止・自動起動 | 一時HOME／ZDOTDIR、実CLI、独立したテスト用ヘルパー | `pnpm run test:shell` |
| Packaging | バージョン付きFormulaの構文・入力検証 | Python標準ライブラリとRuby | `pnpm run test:shell`に含む |

実ヘルパーのCLI検証は、`pnpm run build:release`の後、既存のfigfigヘルパーを終了した状態で`python3 scripts/smoke-cli.py`を実行する。独立した一時設定で起動し、実際のシェル設定やmacOSの権限は変更しない。ディスプレイのあるmacOS環境での検証用で、通常のCIテストとは分ける。

既存実装がない新規プロジェクトのため、上記を初期テスト基盤とする。静的なUI画像の差分テストは、実機レイアウトの基準が固まるまで導入しない。ネイティブの権限・フォーカス・座標はモックの成功を実機での成功と扱わない。

## macOSでの操作確認

`figfig setup`と`figfig permissions`を一度実行し、新しいシェルを開いて、Terminal.appとiTerm2の**両方**で以下を確認する。下記は確認手順であり、CIの合格だけで完了にしない。

- `git ch`で入力位置の近くに候補が出る。キー入力のフォーカスがターミナルに残る。
- 上下で選択、Tab／Enterで挿入、挿入後のEnterで実行する。Esc後は入力を編集するまで再表示しない。
- `git status --s`、`git switch fe`、`pnpm run te`で文脈に沿う候補になる。
- 日本語・空白・引用符を含むファイルを作り、挿入結果が単一の引数になる。
- 日本語IMEで変換・候補選択・確定し、変換操作を横取りしない。
- 複数行の入力、行の折り返し、カーソルを単語の途中へ移動した場合に置換範囲を確認する。
- 別アプリ・タブ・iTerm2の分割ペインへ移動すると候補が消える。移動先で入力すると新しい候補が出る。
- ウィンドウ移動、リサイズ、フルスクリーン、倍率の異なる複数画面、画面下端でポップアップの位置を確認する。
- 権限を外す、アプリを停止する、候補一覧を無効にするなどの状態で、通常のEnter・履歴・Tabを使用できる。
- 手動でアプリを起動せずに候補が出る。設定ウィンドウやメニューバーアイコンが表示されない。
- `figfig pause`／`resume`、`config set history false`、設定の保存と再起動後の読み込みを確認する。
- プロンプトの初期化後にfigfigを読み込み、補完が動作することを確認する。
